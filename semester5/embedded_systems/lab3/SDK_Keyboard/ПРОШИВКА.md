# Самостоятельная прошивка Pong на SDK-1.1M в Linux

Проект настроен под STM32F427VIT6. Скрипт проверяет идентификатор семейства
контроллера перед записью. Средства сборки и OpenOCD берутся из установленной
STM32CubeIDE 1.19.0 в `/opt/st/stm32cubeide_1.19.0`.

1. Подключи стенд кабелем с передачей данных к разъёму **USB DBG / DBG USB**.
2. Если в CubeIDE работает отладка, заверши её кнопкой **Terminate** (красный квадрат).
3. Открой терминал в папке проекта:

```bash
cd /home/user/ITMO/semester5/embedded_systems/lab3/SDK_Keyboard
```

Для записи уже собранной игры:

```bash
bash flash.sh
```

После изменения исходников сначала собери их, затем прошей:

```bash
bash build.sh && bash flash.sh
```

Успешная запись заканчивается сообщениями `** Verified OK **` и
`** Resetting Target **`. На OLED появляется легенда, старт игры — кнопка **2**.
Первый игрок: **1/7**, второй: **3/9**, пауза: **0**, выход в меню: **5**.
После победы до 7 очков воспроизводятся первые 15 секунд предоставленной песни.
Кнопка **5** или новый матч по **2** прекращают воспроизведение.

Собранная прошивка находится в `Debug/SDK_Keyboard.elf`.
Звук хранится во Flash как моно IMA ADPCM, 8 кГц, 4 бита на сэмпл:
120000 сэмплов / 60000 байт, без большого аудиобуфера в ОЗУ.

При ошибке `LIBUSB_ERROR_NO_DEVICE` проверь USB-кабель, переподключи стенд
и повтори `bash flash.sh`. Если отладчик занят, заверши активную отладку CubeIDE
или ранее запущенный OpenOCD, затем повтори прошивку.

При другой установке CubeIDE укажи её каталог, например:

```bash
STM32CUBEIDE_HOME=/opt/st/stm32cubeide_1.19.0 bash flash.sh
```

Сборка использует отдельное временное рабочее пространство и не занимает
открытое рабочее пространство CubeIDE. Скрипт `flash.sh` выполняет только
запись существующего ELF, поэтому после изменения кода нужен `build.sh`.
