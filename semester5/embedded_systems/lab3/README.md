# Лабораторная работа № 3 — Pong

Проект для стенда SDK-1.1M с STM32F427VIT6.

## Состав

- `SDK_Keyboard/` — самостоятельный проект STM32CubeIDE: исходники, конфигурация, необходимые HAL/CMSIS и FreeRTOS.
- `report_lab3.tex` — актуальный исходник отчёта, оформленный по шаблону. Отчёт не требует внешних изображений. Старый PDF не включён, поскольку он не соответствует последней редакции.
- `SDK_Keyboard/ПРОШИВКА.md` — инструкция по сборке и прошивке.

## Сборка и запись

Из каталога `lab3`:

```bash
cd SDK_Keyboard
bash build.sh
bash flash.sh
```

Нужна установленная STM32CubeIDE; по умолчанию используется `/opt/st/stm32cubeide_1.19.0`. Другой путь задаётся переменной `STM32CUBEIDE_HOME`.
Результат сборки создаётся в `SDK_Keyboard/Debug/` и не включается в Git.

Управление: игрок 1 — **1/7**, игрок 2 — **3/9**, старт и повторная игра — **2**, пауза — **0**, выход — **5**. После победы звучит 15-секундный фрагмент аудио.
